# 議事録アプリ　画面の作り替え（v4.1.0）仕様書

2026-10-02　社長の返事（理由：押しにくい＋見た目／場面：PC の Zoom＋スマホの対面／好み：紺と白のまま＋スマホはアプリらしく／残したい所：とくになし／期限：今日中）から作成。

## 1. 何を作るか
議事録アプリ（demo-8bj）の**画面と操作の流れ**を作り替える。
- スマホ：アプリらしい形にする。下にタブを置き、真ん中に大きな録音ボタンを置く。
- PC：横に広い画面を使う。

## 2. なぜ作るか
- **スマホで押しにくい**（375px で測った）
  - ［履歴］［新規］が、画面の上の両端にある。
  - ［録音開始］が、画面の上半分（上から304px）にある。親指が届かない。
  - 「マイクの選択」は押すと開く作りだが、押せる見た目になっていない。
- **見た目を新しくしたい**
  - 10/2 の QB DESIGN.md と、3点ずれている：書体（Noto Sans JP でない）、本文の文字まで紺、地と罫線の色。
  - PC は、画面の右側が空いている。

## 3. 誰が使うか
- 社長 → 数人 → 全員（店長・BM）。
- PC は Zoom の会議で使う（文字起こしあり）。スマホは対面の会議で使う（録音とメモ）。

## 4. 最初のリリースでできること（v4.1.0）
- **スマホ**
  - 下のタブ［会議］［履歴］。タブの真ん中に、大きな丸い録音ボタンを置く。どのタブからでも録音・停止できる。
  - メモの入力は、下のタブのすぐ上に置く。マイクの選択は、時間の下に「マイク：○○」として常に見せる。
- **PC**
  - 左に履歴と設定を置く。右に、横長の「録音のカード」（時間・マイク／マイク＋PCの音・波形2本・録音ボタン）を置く。
  - その下の残りの高さは、全部を文字起こしに使う。
- **見た目**（紺と白のまま整える）
  - 書体は Noto Sans JP。アプリに入れて持つので、外から読み込まない。
  - 本文は黒に近い色（#222）。題・時間・数字は紺。カード・罫線・補足は DESIGN.md の色。
  - 説明の文は、置き場所と大きさだけ整える。**文言は変えない**。
- **確認・入力の窓**：スマホでは下から出す（シート）。PC は今の真ん中の窓のまま。

## 5. 今回やらないこと
- 機能の追加・削除はしない。録音、文字起こし、保存、書き出し、PCの音、波形、×の警告、LINE WORKS の守りは、そのまま。
- 録音・保存・文字起こしの仕組み（sr.js・db.js・capture.js）は書き換えない。
- 案内の文言は変えない（「はじめに」の2行など）。
- ダークモード、ロゴやアイコンの画像化はしない。
- URL の変更と、GitHub の非公開化はしない（別の作業）。

## 6. 画面・機能
**スマホ（幅767pxまで）**
```
┌ QB HOUSE 議事録 ─────────────┐ 上のバー（紺・細め）
│ [帯：文字起こしの案内など]       │
│ 会議 10/02 14:05 ✎   ［新しい会議］│ 会議名（押すと名前を変える）
│ 00:12:34          ● 録音中      │ 時間が主役
│ マイク：既定のマイク ▾            │ 録音していないときだけ
│ マイク ▁▃▅▇▅▃▁                  │ 波形
│ 文字起こしとメモ（ここが動く）    │
│ ［文字(.txt)］［音声］            │ 会議を開いているときだけ
├───────────────────────┤
│ [メモ | 決定 | ToDo]             │
│ [入力欄……………………] [追加]       │ 入力中は、下のタブを隠す
├───────────────────────┤
│   会議      ( ● 録音 )    履歴    │ 録音中は赤い■＝赤はここだけ
└───────────────────────┘
```
- 履歴タブ：［＋ 新しい会議］、記録のカード（押すと会議タブで開く）、いちばん下に設定。
  - 設定は「言いよどみを消す」・容量・版・「音声は端末の外に送りません」。
- 戻るボタン（Android）：履歴タブから会議タブへ戻る。

**PC（幅768pxから）**
```
┌ QB HOUSE 議事録                                   [＋ 新しい会議] ┐
├ 履歴（280px）─┬─────────────────────────────────────────────┤
│ 会議 10/02     │ 会議名 ✎・日時                                     │
│ 会議 10/01     │ ┌録音のカード─────────────────────────────────┐ │
│ …             │ │ 00:12:34 ●録音中 [マイク|マイク＋PCの音]  (■ 録音停止) │ │
│ ───────────── │ │ マイク ▁▃▅▇▅   PCの音 ▁▂▃▂▁   マイク：既定 ▾       │ │
│ 言いよどみを消す │ └─────────────────────────────────────────┘ │
│ 容量・版        │ 文字起こし                      ［文字(.txt)］［音声］ │
│               │ [00:00:01] …（残りの高さ全部）                          │
│               │ [メモ|決定|ToDo] [入力欄………………………] [追加]         │
└───────────────┴─────────────────────────────────────────────┘
```

## 7. データの持ち方
変えない。
- IndexedDB の LocalAIAssistantDB v3 と LocalAIAssistantAudio v1、localStorage の設定は、そのまま使う。
- 今までの記録は、そのまま開ける。
- 画面の部品の ID もできるだけ変えない。通し試験をそのまま使うため。
